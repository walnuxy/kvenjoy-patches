# 奎享雕刻补丁 · Kvenjoy Patches

专门存放奎享雕刻的软件补丁、安装/回滚工具源码、测试和使用说明，不包含原软件或完整逆向工程。

## 跨电脑正式版字体补丁

[下载字体界面累计补丁 v5](dist/kvenjoy-font-patcher-20261022-v5.zip?raw=true) · [SHA-256](dist/SHA256SUMS.txt) · [验证说明](VALIDATION.md)

功能：解除五个字体的选择上限；右侧已选字体支持滚轮；双击左侧加入、双击右侧移除；避免重复加入。

### v5 修复：字体选多后“确定选择”不见

之前中间纵向布局会随优先级输入框数量增长，把“确定选择”挤出窗口。v5将加入、移除、确定三个按钮固定在中间底部，优先级独立滚动，并精简提示，保留可用编辑空间。选择40个字体、缩短窗口时按钮仍完整可见，最后一项优先级可编辑并确认保存。

**v5累计包含v1～v4全部功能**，可从v4直接升级；升级前校验原七个补丁类并备份，回滚恢复升级前原始core。

### v4 新增：按文件夹分类（累计包含 v1、v2、v3）

在正式版安装目录的 `gcodeFonts` 下创建分类文件夹，把字体文件放入对应文件夹：

```text
gcodeFonts/
  草书/字体A.gfont
  行书/字体B.gfont
  楷书/字体C.gfont
  字体D.gfont
```

打开字体窗口，从“文件夹分类”选择草书、行书、楷书等；根目录字体归入“未分类”，“全部”显示所有字体。文件夹名称可自定义，多层目录按第一级分类；不靠字体名字推断书体。

用“打开字体目录”整理文件，点击“刷新”重新加载。筛选只改变左侧显示，右侧已选字体、顺序及优先级保留；搜索、双击增删和箭头仍可使用。可以直接从原版、字体上限版或完整 UI v1/v2/v3 升级。

### v3 优化：路径可以直接粘贴

- 工具启动后，直接Ctrl+V粘贴安装目录或主程序EXE路径，Enter继续，Escape取消；带引号、中文、空格路径均支持。浏览按钮保留为可选方式。
- 安装v3并重启正式版后，公共载入、保存和文件夹选择窗口右侧增加路径输入框。文件夹路径直接定位；文件路径直接选中，再点击原来的打开或保存确认。文件类型筛选、多选返回和取消行为保留。
- 可直接从原版、字体上限版、完整UI v1或v2升级；安装前备份、回滚到本次升级前版本。字体修复继续保留。

### v2 修复：确认后重新打开字体列表为空

已选字体的加载完成通知原本会在界面线程与后台线程各执行一次；后台重复清空 Swing 列表可能使重开后的已选区域显示异常。v2 将回调转交界面线程，忽略同一模型的重复完成通知，并刷新列表和优先级控件。新增回归检查覆盖重开后的字体、顺序、优先级，以及迟到通知保留新选择。

已安装字体 UI v1 的电脑可直接使用 v2 升级，不必先卸载。安装器逐项校验 v1 的四个类，备份升级前的 core；回滚恢复到这次升级前的版本。原版及旧“只解除上限”的版本仍可安装。历史包保留用于复核，新安装请选 v5。

### 使用步骤

1. 在目标电脑正常安装、授权并确认原版奎享雕刻可以运行。
2. 下载 ZIP 并完整解压到独立目录，退出奎享雕刻。
3. 双击 `字体补丁工具.cmd`，选择正式版安装目录（含 `core`、`licene`、`info.txt`、`jre`）。
4. 先选“只检查”；版本兼容后再次运行，选“安装补丁”。
5. 重启原软件，检查六字体选择、右侧滚轮和双击增删。

需要恢复时，退出软件，再运行同一工具选择“回滚”。工具使用目标软件自带的 Java 8，无需安装 Python、JDK，也无需复制逆向工程。

工具读取目标电脑自己的现有封装数据，在内存中重新生成 `core`，仅更新字体界面与公共文件选择器：共七个类（替换r、L，新增三个字体内部类、路径选择器及文件夹分类器）。不会复制、导出或修改授权文件，也不会联网。原 `core` 先备份到安装目录的 `.font-ui-patch`；回滚按原始字节恢复。未知版本、残缺补丁或校验失败会拒绝安装；安装后若 `core` 又被其他更新修改，会停止自动回滚。

本仓库和 ZIP 不包含原版 `core`、本机专用加密补丁、许可、识别码或用户配置。目标软件安装目录受 Windows 权限限制时，需要以具有该目录写权限的身份运行工具。

### 与开发版的区别

本工具服务于另一台电脑已有授权的**正式版**。完整工程中的 `tools/run_fontui_runtime.ps1` 只启动隔离开发版；它不在本仓库，也不是正式版安装入口。不要把开发 JAR 改名为 `core`，不要跨电脑复制本机加密的 `core-font-ui`。

## 本仓库内容

- `dist/`：可直接解压使用的字体补丁 ZIP、SHA-256。
- `src/FontPatcher.java`：安装、兼容检查、备份和回滚源码。
- `tests/FontPatcherTest.java`：合成目标安装的回归测试。
- `src/com/kenjoy/kenjoycnc/fonts/r.java`、`FontFolderFilter.java`、`tests/FontUiChecks.java`：本次字体对话框修复及UI回归源码。
- `build.py`：从源码重建安装器，复用补丁 ZIP 中七个类及兼容指纹。
- `字体补丁工具.cmd`、`run-font-patcher.ps1`：启动脚本源码；普通用户请使用 ZIP 内完整文件。

## 重建安装器

构建电脑需要 Python 3.10+ 和 JDK 9+（已用 JDK 21 验证）。目标安装电脑不需要它们。

```powershell
python build.py --jdk "C:\Path\To\jdk-21"
```

输出 `build/font-patcher.jar`。把它放到两个启动脚本旁可运行；预编译的七个补丁类及兼容指纹来自发布 ZIP。本脚本重建安装器，不重编译字体界面。

测试还需要合法取得的原始明文 core JAR 和旧字体上限 v2 类；这些参考文件不在公开仓库中。

```powershell
python build.py --jdk "C:\Path\To\jdk-21" --test-java "C:\Path\To\App\jre\bin\java.exe" --reference-core "C:\Private\core-restored.jar" --legacy-v2 "C:\Private\r.v2.class"
```
