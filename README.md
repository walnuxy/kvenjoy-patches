# 奎享雕刻字体补丁 0.007

[下载完整安装包 0.007](dist/kvenjoy-font-patcher-20261022-0.007.zip?raw=true) · [校验值](dist/SHA256SUMS.txt) · [验证说明](VALIDATION.md)

字体窗口支持中文、英文、符号、其他语言和喜好字体分类。选中字体后点击“加入喜好”，以后从“喜好字体”筛选；收藏保存在用户目录 `.KenjoyDraw/font-favorites.properties`。文件夹筛选与语言筛选共同生效，查看所有喜好时将文件夹选为“全部”。

本包包含可直接运行的安装器和 **70 套新增字库**：中文 3、英文 55、符号 8、其他语言 4。新增中文黑体、楷体各 20,976 个字形，明朝体 27,632 个字形。英文通常只有几十到几百个字形；这个数量不能当作中文字库大小。原软件已有的字体继续保留，各电脑最终总数不同。

0.007 修复转换字体的中心/基线坐标及预览示例字，并缩短列表描述。已安装过本地 0.006 字库的电脑会备份并修复对应字体。红色辅助线是原软件的预览参考线。

## 安装

1. 完整解压本包，或完整解压 GitHub 的 Code → Download ZIP。根目录已经包含 `font-patcher.jar`，无需编译。
2. 退出奎享雕刻，双击 `字体补丁工具.cmd`。
3. 粘贴正式版安装目录或主程序 EXE 路径；目录应包含 `core`、`licene`、`info.txt`、`jre`。
4. 选择“安装补丁和字库”，成功后重新打开软件及字体窗口。
5. 在“字体分类”中选择中文、英文、符号等，点击“刷新”更新列表。

工具使用目标软件自带的 Java 8，无需安装 Python/JDK。安装器和字库都在 JAR 中，文件缺失会明确提示补丁包不完整。

## 分类和字库

新增字体存放在 `gcodeFonts/中文`、`英文`、`符号`、`其他语言` 下。已有字体按字形编码自动识别；也可手动放入以上文件夹指定分类。部分符号字体借用拉丁字母键位存储图案，按所属文件夹归为符号。签名字体应放入“符号”。

新字体保留笔画和抬笔；部分源字体本身是双线或多线设计。软件以 Java char 寻址，因此不包含补充平面汉字和多字符连字，也不保留 SVG 字距对。

来源：[LingDong-/chinese-hershey-font](https://github.com/LingDong-/chinese-hershey-font)（中文）和 [msurguy/stroke-font-studio](https://github.com/msurguy/stroke-font-studio)（英文、符号等）；上游固定提交和逐字体清单见仓库 `fonts/`。原字体声明和许可保存在 JAR 的 `fonts/licenses/` 中，可用 ZIP 工具打开查看。字体遵循各自的 MIT、SIL OFL 或 Hershey 许可条件。

## 备份与回滚

安装前将原 `core` 备份到 `.font-ui-patch/core-<SHA256>.bak`。工具读取本机已有数据进行兼容检查，不修改 `licene`、`info.txt` 或机器配置。已存在同内容字体会跳过；只替换已知 0.006 转换版本，不覆盖同名的其他字体。旧字库备份到 `.font-ui-patch/fonts-before-0.007/`。

选择“回滚界面”会按字节恢复本次升级前的 core；新增字库和喜好记录保留。未知或被修改的 core/字体会拒绝覆盖。支持原版、历史字体补丁 0.001～0.005 及本地 0.006 升级。

累计保留：解除 5 字体上限、已选列表滚动、双击增删、40 字体时确认按钮可见、优先级编辑、载入/保存路径输入。

非交互用法：`java -jar font-patcher.jar --check|--apply|--rollback 软件目录`。其中 `--apply` 安装界面和新增字库；`--rollback` 仅回滚界面。

## 重建安装器

构建电脑运行 `python build.py --jdk "C:/Path/To/jdk-21"`，生成 `build/font-patcher.jar`。它复用发布包中的七个补丁类、兼容指纹和字库资源。目标安装电脑无需构建。历史包保留用于兼容升级测试。
