# 奎享雕刻补丁 · Kvenjoy Patches

专门存放奎享雕刻的软件补丁、安装/回滚工具源码、测试和使用说明，不包含原软件或完整逆向工程。

## 跨电脑正式版字体补丁

[下载字体补丁工具 v1](dist/kvenjoy-font-patcher-20261022-v1.zip?raw=true) · [SHA-256](dist/SHA256SUMS.txt) · [验证说明](VALIDATION.md)

功能：解除五个字体的选择上限；右侧已选字体支持滚轮；双击左侧加入、双击右侧移除；避免重复加入。

### 使用步骤

1. 在目标电脑正常安装、授权并确认原版奎享雕刻可以运行。
2. 下载 ZIP 并完整解压到独立目录，退出奎享雕刻。
3. 双击 `字体补丁工具.cmd`，选择正式版安装目录（含 `core`、`licene`、`info.txt`、`jre`）。
4. 先选“只检查”；版本兼容后再次运行，选“安装补丁”。
5. 重启原软件，检查六字体选择、右侧滚轮和双击增删。

需要恢复时，退出软件，再运行同一工具选择“回滚”。工具使用目标软件自带的 Java 8，无需安装 Python、JDK，也无需复制逆向工程。

工具读取目标电脑自己的现有封装数据，在内存中重新生成 `core`，只替换字体对话框及三个内部类。不会复制、导出或修改授权文件，也不会联网。原 `core` 先备份到安装目录的 `.font-ui-patch`；回滚按原始字节恢复。未知版本、残缺补丁或校验失败会拒绝安装；安装后若 `core` 又被其他更新修改，会停止自动回滚。

本仓库和 ZIP 不包含原版 `core`、本机专用加密补丁、许可、识别码或用户配置。目标软件安装目录受 Windows 权限限制时，需要以具有该目录写权限的身份运行工具。

### 与开发版的区别

本工具服务于另一台电脑已有授权的**正式版**。完整工程中的 `tools/run_fontui_runtime.ps1` 只启动隔离开发版；它不在本仓库，也不是正式版安装入口。不要把开发 JAR 改名为 `core`，不要跨电脑复制本机加密的 `core-font-ui`。

## 本仓库内容

- `dist/`：可直接解压使用的字体补丁 ZIP、SHA-256。
- `src/FontPatcher.java`：安装、兼容检查、备份和回滚源码。
- `tests/FontPatcherTest.java`：合成目标安装的回归测试。
- `build.py`：从源码重建安装器，复用补丁 ZIP 中四个类及兼容指纹。
- `字体补丁工具.cmd`、`run-font-patcher.ps1`：启动脚本源码；普通用户请使用 ZIP 内完整文件。

## 重建安装器

构建电脑需要 Python 3.10+ 和 JDK 9+（已用 JDK 21 验证）。目标安装电脑不需要它们。

```powershell
python build.py --jdk "C:\Path\To\jdk-21"
```

输出 `build/font-patcher.jar`。把它放到两个启动脚本旁可运行；预编译的四个字体补丁类及兼容指纹来自发布 ZIP。本脚本重建安装器，不重编译字体界面。

测试还需要合法取得的原始明文 core JAR 和旧字体上限 v2 类；这些参考文件不在公开仓库中。

```powershell
python build.py --jdk "C:\Path\To\jdk-21" --test-java "C:\Path\To\App\jre\bin\java.exe" --reference-core "C:\Private\core-restored.jar" --legacy-v2 "C:\Private\r.v2.class"
```
