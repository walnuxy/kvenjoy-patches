# 奎享雕刻累计更新补丁 0.027

完整解压，保存并退出软件，再双击 **一键更新.cmd**。选择原安装目录或 EXE，安装后重新打开软件。已安装公开 0.026 的用户可直接升级。使用更新器的「只检查」确认实装版本，命令行校验应输出 `VERIFIED 0.027 vendor`。

- 笔记支持按字选择续写。中断后保留发送进度，预览标出软件已收应答和可能写到的字，可用右键或侧栏设定起点。继续前请先确认纸面进度和机器的起写原点。
- 已选字体和权重合在同一列表，修改权重时可直接对照同行预览。
- 修复串口发送线程阻塞时进度刷新和清除任务拖住界面的问题。点击书写会在后台核对所选串口，断线后的旧任务不会自动重发。

软件回滚使用更新器的「回滚本次更新」，回滚前请保存文稿并关闭软件。0.019 独立版保留原业务和 0.020 界面层。细节见 [续写操作说明](INLINE-EDITOR.md)、[兼容记录](COMPATIBILITY.md) 和 [验证记录](VALIDATION.md)。
