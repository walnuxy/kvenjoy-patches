# 奎享雕刻累计更新补丁 0.022

一次升级到当前字体、笔记与全窗口界面功能，无需依次安装历史补丁。完整解压，保存并退出软件，双击 **一键更新.cmd**，粘贴软件目录或主程序 EXE 路径，再点击 **一键更新**。自动备份、检查、更新与校验；完成后重新打开软件。目标电脑使用软件自带运行时，无需 Python 或 JDK。

## 版本号

当前正式发布号为 **0.022**，上一公开补丁为 0.021。仅正式发布递增版本。本轮原安装版载荷对应已验证的本机批次 `20261025-184926-740635`；旧 EXE 标题及历史收据不改写。

## 兼容范围

支持本项目留存的原版、早期 v1～v4 字体补丁、0.001～0.008 字体系列、0.009～0.011 笔记阶段、0.012～0.018 界面预装阶段，以及 0.019 独立版、0.020/0.021 累计补丁。兼容检查按实际类指纹识别，不按文件夹名或版本字符串判断。0.009 等历史编号并非每个都曾单独公开发布；具体留存输入与实测结果列在 `COMPATIBILITY.md`。未知或修改过的业务组件会明确停止，避免覆盖第三方改动，不能据此承诺兼容未提供的其它厂商发行物。

原安装版在目标电脑本地更新 core，保留原启动器、授权文件与本机数据；请先确认原软件能够正常打开。0.019 独立版保留原启动链、运行时及业务类，仅沿用 0.020 已验证的界面层载荷；0.022 的跨模式打开、笔记“更新”和默认字体等业务修复仅适用于原安装版。本补丁不会把两个分支互相转换。**0.022 是累计补丁版本**，不替换旧 EXE；原 EXE 或独立版标题仍可能显示原产品版本。

## 本次新增

- 特殊字符不再阻断整篇文章载入；常见缺失标点使用内置笔画补全。
- 仍缺少字形的字符保留原文、预览显示红框，打印/导出留空，红框和问号不会输出。
- “清除红框…”仅在有红框时出现，可将整篇所有红框替换为空格或全部删除，支持撤销、重做。
- 本轮文章修复适用于原安装版；0.019 独立版仍保留此前业务类。

## 累计内容

- 字体多选、滚动、分类、收藏、优先级与文件路径输入；大量字体时确认按钮保持可见。
- 笔记编辑、纸张模板、排版、选字指定字体、撤销重做、分页预览及批量导出。
- 全窗口深色主题、适配显示器的默认窗口、响应式工作区、原生 DPI 字体及细圆角边框；修复弹窗裁切、模式切换间距和图标缩放。
- 原安装版文件菜单汇总现有格式并自动切换适用模式；修复启动错误、笔记“更新”的重新随机语义、新建笔记默认字体、PDF 页状态与跨模式打开失败回退。十种模式侧栏及模式图标统一样式。
- 将界面与加工 DPI 分离。原安装版保留升级前的加工比例；自定义加工 DPI 和已有启动参数保留。0.019 独立版沿用自身业务设置与现代运行时的 DPI 处理。
- 包含原 70 套可再分发字库与来源许可；缺少的 15 套中文手写字体按固定 URL 和 SHA-256 下载、校验并归类。首次补齐需联网约 51 MB。下载失败会在写入软件前停止。已有同内容字库跳过，同名不同内容保留并提示，不覆盖个人字库。

字体继承 0.008 的来源及许可要求，详见 `FONTS.md`。15 套下载字库不重新托管，也不授予额外使用许可。

## 备份与回滚

备份位于目标目录 `.kvenjoy-update/txn-…`。使用同一工具选择 **回滚本次更新**，可精确恢复本次改动的软件主文件、EXE 启动选项、被替换或移动的字库，并移除本次新增且未再修改的字库；文章、个人设置和原有字库不回退。重复更新不会覆盖备份。若被更新的文件随后又有变化，工具拒绝覆盖，保留后续改动。安装写入失败自动恢复本次已经写入的文件；若断电或强制结束，先执行回滚，再重新更新。

安装和回滚均需先退出所选软件；启动脚本会检查该目录运行中的 EXE/Java 进程，不会替你关闭软件。

命令行：`java -jar update-patcher.jar --check|--apply|--rollback 软件目录`。`--apply` 包含字库准备和累计更新；调用前自行保存并退出目标软件。补丁不连接雕刻设备。

## 构建与验证

开发者用 `python rebuild.py --jdk C:/Path/To/JDK` 重建安装器，输出 `build/update-patcher.jar`。公开包中的差量类、指纹和字体资源可复用，不需要原软件和个人授权数据。此命令只重建安装器，不声称能从公开源码重建原软件。

测试方式、历史输入、边界与校验值见 `VALIDATION.md`、`COMPATIBILITY.md` 和 `SHA256SUMS.txt`。完整历史回归需要开发者自己持有原始参考文件；公开仓库不提供完整 core、许可、个人数据或独立版全量发行包。
