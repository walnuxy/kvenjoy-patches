完整解压，保存并退出软件，双击 **一键更新.cmd**，选择安装目录或主程序EXE，再点击“一键更新”。自动备份、更新与校验，支持精确回滚；目标电脑使用附带Java，无需Python/JDK。

## 版本与安装确认

当前公开补丁 **0.025**，上一公开补丁0.024。本轮原安装版载荷与已验证本机批次`20261105-110051-963558`的解密类及资源逐条相同。正式发布才递增；历史安装收据和旧EXE标题不改写，不能凭标题判断更新是否成功。

安装后重新启动；再次运行工具“只检查”，应显示“当前载荷已符合累计补丁0.025”。“可更新至”仅表示兼容。还可用目标自带Java运行`java -jar update-patcher.jar --verify 软件目录`，应输出`VERIFIED 0.025 vendor`。不同电脑的加密core散列不要求相同。

## 备份与回滚

备份位于目标目录 `.kvenjoy-update/txn-…`。使用同一工具选择 **回滚本次更新**，可精确恢复本次改动的软件主文件、EXE 启动选项、被替换或移动的字库，并移除本次新增且未再修改的字库；文章、个人设置和原有字库不回退。重复更新不会覆盖备份。若被更新的文件随后又有变化，工具拒绝覆盖，保留后续改动。安装写入失败自动恢复本次已经写入的文件；若断电或强制结束，先执行回滚，再重新更新。

程序回滚不转换文章格式。新.kjnote格式2可读旧1；直接编辑前旧程序不能读2，旧格式2读写可能忽略/丢失蓝框。回退前请保留新文章原件，用副本测试。

安装和回滚均需先退出所选软件；启动脚本会检查该目录运行中的 EXE/Java 进程，不会替你关闭软件。

命令行：`java -jar update-patcher.jar --check|--verify|--apply|--rollback 软件目录`。`--apply` 包含字库准备和累计更新；调用前自行保存并退出目标软件。补丁不连接雕刻设备。

## 构建与验证

开发者用 `python rebuild.py --jdk C:/Path/To/JDK` 重建安装器，输出 `build/update-patcher.jar`。公开包中的差量类、指纹和字体资源可复用，不需要原软件和个人授权数据。此命令只重建安装器，不声称能从公开源码重建原软件。

测试方式、历史输入、边界与校验值见 `VALIDATION.md`、`COMPATIBILITY.md` 和 `SHA256SUMS.txt`。完整历史回归需要开发者自己持有原始参考文件；公开仓库不提供完整 core、许可、个人数据或独立版全量发行包。
