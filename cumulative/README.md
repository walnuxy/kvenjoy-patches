# 奎享雕刻累计更新补丁 0.026

完整解压，保存并退出奎享雕刻，双击 **一键更新.cmd**，选择原软件安装目录或 EXE。安装后重新打开软件。「只检查」可核对实际载荷，也可运行 `java -jar update-patcher.jar --verify 软件目录`，应输出 `VERIFIED 0.026 vendor`。

支持从公开 0.025 直接升级。0.019 独立版沿用 0.020 界面层和自己的业务类。首次补齐缺少的字体需要联网，见 [字体来源](FONTS.md)。

回滚前保存文稿并退出软件，再从更新器选择「回滚本次更新」。软件回滚不会转换笔记格式，含禁写区的 V4 文稿请保留原件，回到旧软件时使用升级前备份或兼容副本。

## 本次更新

- 新增禁写区管理、奇偶页和单页例外、偶数页镜像、安全边距、JSON 模板，以及在预览中绘制、选中和编辑区域。
- 笔记侧栏三个分区可独立折叠，翻页入口固定在「书写来源」下方，运行任务保留启动页。
- 打开、导入、保存、导出和目录选择统一使用 Windows 原生文件窗口。
- 字形规整和关联随机支持英文与数字分别调节大小，修复字体收藏与加载、手动串口和暂停后的进度。
- 修复长串标点换行、禁写区单页例外保存、下载字体页控件禁用，以及禁写区校验失败后保留输入。
