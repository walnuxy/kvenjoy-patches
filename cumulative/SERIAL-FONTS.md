# 自动连接与字体缓存（0.024）

## 修改范围

原安装版的生产启动链接入后台 USB 串口发现，每两秒检查一次插拔。按 USB PNP 身份记住成功设备和波特率，端口号可变化；默认排除蓝牙和 Quectel。单个已识别 USB 串口适配器可自动连接，多个设备或未知 USB 设备需要选择。提供自动连接开关、搜索、取消和超时提示。

旧连接扫描逐个尝试全部 COM 端口。旧 EBB 初始化还会启动异步参数发送器，旧 Grbl 初始化会发送复位。新搜索连接绕过这些初始化，只发送固件识别查询（Grbl `$I`、EBB `V`、Marlin/K_AT `M115`），必须收到对应固件身份并由原固件处理器确认才成功。启用状态更新时，Grbl 状态轮询在确认后恢复（只读）。不会发起书写、机械回零、抬落笔或机器参数写入。手动断开与搜索取消后不会立即自动重连；断线后要求手动重新搜索，任务不会自动恢复。

字体原流程每次清空列表，重新解析所有预览，逐项同步到 EDT，关闭窗口还强制垃圾回收。新流程分离目录/头信息、完整字库和预览缓存；以路径、大小、修改时间增量更新，复用未改变条目。字体窗口即时使用已有列表，仅可见项请求后台预览；主界面刷新与默认字体窗口共享目录快照。并发刷新合并，取消后旧回调不会覆盖新列表；扫描失败保留旧快照，损坏文件单独列出。分类、空文件夹、喜好、配比及文章字体绑定保持，刷新不会重新随机文章字形。

## 同机测量

2026-10-25，本机软件自带 Java 8，同一目录 155 个 gfont 文件，其中 152 个符合当前产品标识。生产 0.023 字体窗口作基线，新窗口在隔离设置、隐藏桌面下测量三次：

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 重复打开窗口可操作 | 4–10 ms | 3–9 ms |
| 重复打开列表就绪 | 624–817 ms | 8–18 ms |
| 重复扫描目录 | 约 3 ms | 约 3–6 ms |
| 每次解析预览 | 约 325–330 ms，全量 | 已缓存项为零，未缓存可见项后台解析 |
| 未变化目录增量刷新总计 | 每次重新读取/解析 | 约 6–10 ms，复用 152 项 |

这些是本机结果，不代表另一台电脑必然同速；旧窗口本身已经异步显示，主要改善的是字体列表可用时间和重复工作。原始记录保存在 font-ui/baseline-timings.txt、optimized-timings.txt 和 performance 下。

## 验证与边界

- Java 8/JDK 21 模拟串口：20 项，包括启动前已有设备、热插拔、COM 变化、多个候选取消、占用、握手失败/取消/超时、已连接不重复打开、手动断开和断线不恢复任务。另检查普通 `ok` 与错误固件不能冒充识别成功，安全打开不调用旧复位/参数发送。
- 字库缓存：12 项，包含新增、修改、删除、损坏文件、失败保留列表、预览复用和并发合并。
- 字体窗口既有交互回归通过，包括分类、收藏、滚轮、多字体选择、配比保存与重开恢复。
- 实际候选 core 使用独立类路径回归并通过原厂加密加载器启动检查；构建校验覆盖新增连接类及完整字体覆盖类，防止遗漏配套类再次导致 error-4。
- 本机只发现两个蓝牙串口，未发现 CH340；没有连接实体设备。另一台电脑仍需验收 CH340 插拔、实际固件响应与端口占用。握手不成功会显示失败并关闭端口，不把打开 COM 当作成功。
- 0.019 独立版沿用此前已验证的界面载荷；本轮业务功能针对原安装版。

## 另一台电脑验收

保存文章、退出软件后安装 0.024 累计包，重新打开。分别测试机器先插后开、先开后插、换 USB 口、两个 USB 串口同时存在、端口被其它程序占用、取消搜索及手动断开。成功提示须包含固件确认；整个连接过程不应产生机器动作。默认字体窗口连续开关三次，并在后台加载时滚动、取消、关闭；添加/替换/删除测试字体后刷新，检查列表与文章选择。
