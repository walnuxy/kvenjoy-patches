# 0.027 实机测试与Bug采集

这是公开发布包附带的现场工具，只用Windows PowerShell5.1，不需要Python/JDK。先完整解压，保存退出软件，用上级目录“一键更新.cmd”安装0.027，再启动软件。更新器“只检查”若显示“当前载荷已符合累计补丁0.027”，表示实际组件匹配；“可更新至”只表示兼容，尚未证明已安装。

也可在PowerShell用目标软件自带Java核验（路径改为实际位置）：

```powershell
& 'D:\软件\奎享雕刻\jre\bin\java.exe' -jar '..\update-patcher.jar' --verify 'D:\软件\奎享雕刻'
```

须输出`VERIFIED 0.027 vendor`。不同电脑本地加密core散列可能不同，不能拿源电脑core SHA作为目标机应有值。旧公开0.024与旧测试包不含本次全部更新。

把“给另一位Codex.md”交给现场Codex，并按“测试流程.md”填写结果。由现场操作者确认机器动作，Codex可自行进行离线测试和被动采集。流程中的“安装测试补丁/验证构建”指本公开包的累计安装器及上述校验；本目录没有私有测试安装器或Git bundle。

1. 双击`01-开始采集.cmd`，填写目标安装目录；它不启动程序、不连接设备。
2. `02-记操作时间.cmd`记录测试用例、刚做的操作；异常先记时间，安全稳定后用`03-记录Bug.cmd`补步骤、预期、实际、机器状态和复现次数。
3. 手工将测试稿副本、对应G-code/图片/PDF、截图/录像和脱敏错误片段放进本轮`Sessions\时间编号\attachments`。
4. `04-采集状态.cmd`看心跳；`05-结束并打包.cmd`得到本轮ZIP。回传ZIP和填写的测试结果。补附件后可再次结束打包。

每5秒采集目标进程PID、累计CPU秒、内存、线程/句柄及响应标志；阶段标记时枚举COM设备显示名；开始时记录系统/显示器概况、程序/字体散列。它不读取许可内容、文章、完整配置、运行日志，不自动截图，也不打开串口。记录仍含本地路径/字体名及人工文字，回传前检查。请勿上传Sessions目录到公共仓库。

“未响应”或CPU/内存变化只是线索；端口存在不证明固件确认；采集器无法证明命令执行、任务冻结或机器停机。不要用第二个串口终端抢占软件的COM。意外运动先由操作者现场急停，再保全证据；不得通过反复点击书写、强杀软件或运动中拔线试探。

测试顺序：离线编辑/保存恢复 → 串口连接 → 小范围空跑 → 短文落笔 → A稿运行时改B稿 → 中止与静止断线/恢复。未完成或条件不足的项记BLOCKED/NOT_RUN，不填PASS。真实行程、速度、笔控、原点与固件由现场确认，本包不提供通用可直接发送的G-code。
