# 实机测试流程与结果记录

预计90–120分钟；每阶段根据现场进展调整。任何项目都可记录 `PASS / FAIL / BLOCKED / NOT_RUN`，没有证据时不填PASS。请另存本文件填写结果，记录目标安装目录、构建验证输出、操作者、设备型号、固件及版本、驱动版本、连接方式、COM/波特率、屏幕缩放、所选字库/权重、纸张和加工参数。不要用源电脑的设备设置直接覆盖目标设置。

动作授权：下列步骤是测试清单，不是给Codex持续发设备命令的授权。Codex可自行做只读采集和离线测试；回零、点动、抬落笔、空跑、落笔书写、故障注入分别由现场操作者明确同意并控制。首次连接先确认驱动、固件类型、速度、笔高度、坐标/限位和急停方式。串口打开可能引起控制板复位，现场观察。物理测试用合成短文和废纸，先确认有效工作范围，不预设通用安全速度/行程。

## 0. 版本与基线（约10分钟）

| ID | 操作 | 预期与证据 | 结果/事件ID |
|---|---|---|---|
| V01 | 原版离线启动，记设备/电脑基线，退出后安装测试补丁 | 安装成功且“验证测试构建”输出VERIFIED；保存输出 | |
| V02 | 开始采集，再启动原EXE | 黑色预览、编辑入口可见；心跳持续更新、软件进程有数据 | |
| V03 | 先不连接机器，打开已有文章副本 | 正文/页码/字形正常；不自动开始书写或回零 | |

若原版本来不能启动、授权无效、补丁检查拒绝未知组件：先记录基线故障，标为BLOCKED，不绕过检查、不复制源电脑core或许可。保持现有环境供定位。

## 1. 离线编辑、缺字与恢复（约25分钟）

| ID | 操作 | 预期与证据 | 结果/事件ID |
|---|---|---|---|
| E01 | 导入`samples/01-编辑与标点.txt`；选择2–3种字体及非等权重，进入编辑态；中文IME选词、取消预编辑、英文连续输入、退格、删除、Enter；快速重复一小段 | 不丢字/重复上屏；光标/IME候选位置合理；仅确认输入进入正文，正常旧字形保持 | |
| E02 | 点击行尾/空白、Home/End/方向键、Shift选区；整页/页宽/手动缩放、窗口还原最大化；导入02长文跨页滚动拖选 | 位置正确，空白点击不凭空补空格；跨页选择/自动跟随可用，控件不遮挡 | |
| E03 | 手动指定几字字体；复制粘贴一段；再同文章剪切移动；撤销/重做 | 复制的新字按当前权重抽样；剪切保持原字形/字体；撤销重做恢复当次结果、不重新抽样 | |
| E04 | 改默认字体/权重后输入；点一次“更新”，再撤销 | 默认设置只影响后续新输入；“更新”重随机已有自动字，手动字体保留；撤销恢复此前结果。短文不要求精确按比例分配 | |
| E05 | 检查`.`、`．`、`。`，导入03含emoji缺字；缺字/生成未完成时尝试新导出（设备保持断开） | 两种点正确显示，原文码点不变；缺字原文保留并红框；导出明确阻止，不输出上一次旧预览。断开时点击书写只验证连接门槛，不算缺字书写门槛通过 | |
| E06 | 红框→指定字符替换为英文`.`；撤销/重做；保存重开；再以不支持字符尝试替换 | 整篇红框替换、改处蓝框；正常字不变，保存恢复标记；不支持字符拒绝且无正文/历史副作用。可另测空格替代、删除 | |
| E07 | 等待布局完成后导出图片/PDF/G-code；以90°加工方向进入/退出编辑 | 屏幕黑底浅笔迹，输出白底黑笔迹；红蓝框/光标/临时字不进入输出；编辑正向，退出及输出保持加工方向 | |
| E08 | 仅在断开设备后：默认自动恢复下编辑未保存新稿，等采集标记后正常退出重开；再测试“关闭前询问保存” | 恢复正文、确定字形、蓝框、位置；主动保存的原文件不被恢复稿自动覆盖；询问模式可取消退出 | |

E08不默认强杀进程；若专测崩溃恢复，只在独立测试稿、设备断开、已另存副本且操作者同意时进行。先保存恢复稿副本及事件时间，不能以`recovery.json`存在代替内容对照。统计分布需足够样本且字体均支持测试字符、无零权重；发现可疑先保存文章，不凭十几个字判断权重错误。

## 2. 串口连接与状态（约15分钟）

| ID | 操作 | 预期与证据 | 结果/事件ID |
|---|---|---|---|
| C01 | 经操作者同意：设备静止时，启动前插入/运行后插入USB，测试自动连接开关 | 发现正确串口，确认固件身份后才标已连接；不书写/回零/参数写入；记是否发生硬件复位 | |
| C02 | 有多个候选时选择；手动取消搜索；静止时换USB口并重新发现 | 选择/取消/超时说明清楚；不把COM号当永久身份；不误连蓝牙等其它设备 | |
| C03 | 静止时手动断开与重新连接；条件允许再测端口占用/不匹配固件设置 | 状态及时一致，错误可读；仅COM打开不算握手成功；失败不自动开始旧任务 | |
| C04 | 已验证连接且静止、操作者同意后：取消外部G-code来源，不走K_AT队列，确认来源为当前笔记页；用含红框测试稿点击书写 | 因笔记未就绪明确阻止，不发送任何运动路径；仅显示连接错误不算本项通过。条件不满足标NOT_RUN，不重复尝试 | |

不启用第二个串口终端抢占软件已打开的端口。C03的占用/不匹配属于可选故障注入，仅在操作者明确同意、静止状态做；不随意发送配置/解锁/回零指令。记录真实固件，不假定所有设备都是Grbl。

## 3. 小范围空跑和短文落笔（约15分钟）

| ID | 操作 | 预期与证据 | 结果/事件ID |
|---|---|---|---|
| M01 | 操作者确认机械范围、笔已可靠离纸、坐标及速度；按现场设备提供的方法执行一小段空跑 | 实际起点、方向、行程与当前页路径相符，无超范围；不得仅靠软件“抬笔”图标判定离纸 | |
| M02 | 用04短文，操作者同意后在废纸落笔，先单页少量字符 | 与导出路径及预览对应，点/换行/抬落笔正确；测量一段已记录的目标间距并拍照，对照实际毫米/方向 | |

本包故意不提供可直接发送的通用G-code：不同固件、笔控方式、原点与机械范围不同。用目标配置从同一测试文章生成路径，先离线查看，再由操作者确认。尺寸误差保留目标数值、实测值、比例、测量照片和Windows缩放，先定位界面DPI/加工DPI/固件步进参数层级，不能立即改固件。

## 4. 正在书写时编辑下一稿（约10–20分钟）

| ID | 操作 | 预期与证据 | 结果/事件ID |
|---|---|---|---|
| M03 | 从05的A稿保存文章与G-code作对照；**取消外部G-code来源，确认界面来源是当前笔记页且不是K_AT队列**，标记开始并启动该任务；运行中改成05的B稿，再更新字形、改字体/翻页 | 当前任务始终执行启动时A稿、页码和路径；界面能区分当前稿与任务来源，编辑不改任务方向/尺寸。直接发送预导出的A.gcode不算本项通过；K_AT队列另记 | |
| M04 | A稿完成，确认停机/纸张/坐标后，明确启动B稿 | 下一任务才用B稿；A/B结果、对应文章/G-code、连续录像可互相对照 | |

先核对源码/现有回归支持该交互，再按小任务执行。不要靠机器上看到几个旧字就宣布冻结正确。需完整任务与A稿路径一致。多页预览不是自动换纸或自动顺次执行全部页面：当前笔记任务冻结**启动时当前页**，每一页独立确认。

## 5. 中止、断线与恢复（约15分钟）

| ID | 操作 | 预期与证据 | 结果/事件ID |
|---|---|---|---|
| R01 | 对小任务，操作者测试软件停止/取消，现场观察并确认机器真正停止 | 记录点击、软件显示、最后运动时间及任务状态；停止不等于物理急停 | |
| R02 | **确认静止后**测试USB断开重连；记录端口枚举及界面 | 断线状态一致，旧队列不自动恢复/重发，无自行回零或书写 | |
| R03 | 出现中断任务时，仅在确认停机后点“清除中断任务…” | 清除仅解软件任务锁，不启动任务；生成器尚未退出时保持禁用；迟到回调不复活旧任务 | |
| R04 | 重新确认坐标/纸张后手动开始一份新短任务 | 新任务可运行，旧任务不混入；不重复点“书写”来试探 | |

不把“运动中拔线”作为首轮默认测试。要测时须另定现场停机方案并由操作者明确授权。断开软件/结束程序不保证固件缓冲已清空；运动异常先现场急停。等待提示超过30秒是说明，不是自动重发或丢弃任务的阈值。没有可控条件可直接标NOT_RUN。

## 故障处理和最小证据

先处置机器安全，再记“02”时间标记；不要急着反复点书写/重连/更新。用“03”记步骤、预期、实际、物理状态和复现次数，随后保存**副本**、截图和对应导出路径；当时无法保存则记录原因，保留窗口和恢复稿供Codex定位。失败后不覆盖唯一原稿。

建议严重度：P0意外运动/限位风险；P1正文丢失、错误稿被书写或不可恢复；P2连接/编辑/保存/尺寸功能错误；P3纯视觉。先记事实，根因单列为假设。不能通过的阶段不要以“基本正常”替代；物理阶段受阻时允许完成离线部分，但总体实机结论保持未完成。

每个Bug至少包含：事件ID/本地与UTC时间、构建验证、用例ID、准确步骤、预期/实际、机器是否运动及停机确认、复现次数、文章/导出/截图引用。新旧程序对比用副本并逐次确认构建；回退不转换格式2文章。
