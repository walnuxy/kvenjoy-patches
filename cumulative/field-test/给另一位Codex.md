# 给现场Codex：奎享雕刻0.026

你接手的是Windows Java Swing桌面软件的补丁实机验收。先读上级README.md、INLINE-EDITOR.md、VALIDATION.md，以及本目录README.md、测试流程.md。当前正式公开补丁0.026，基础软件由用户本来拥有的原安装版提供，更新器按目标本地许可重封装；不复制别台core或许可。公开仓库为walnuxy/kvenjoy-patches，只包含白名单补丁、相关源码与可再分发资源，不是完整原软件或私有研究工程。

## 先确认实际程序

源码存在、EXE标题或更新器显示“可更新至”不等于安装完成。保存退出后通过累计更新器安装0.026，重新启动；用“只检查”的“当前载荷已符合”结果，或`java -jar update-patcher.jar --verify 软件目录`输出`VERIFIED 0.026 vendor`核对实际组件。包的SHA见上级SHA256SUMS.txt。目标core是本机加密，和其它电脑SHA不同是允许的。

0.019独立版继续沿用0.020界面层，保留原业务类，不包含0.026新增直接编辑、笔记和串口业务修复；不能用独立版验收本轮原安装版新功能。全量独立版与原版不随公开包提供。

## 项目结构

公开包`src/com/kenjoy/kenjoycnc/processTabs/NoteTab.java`管理正文、异步布局、输出门槛与当前页任务冻结；`g.java`管理画布、IME、caret、选区与跨页显示。`note/NoteEditSession.java`管理逐字身份与历史；NoteDocument管格式2和蓝框标记；NoteLayoutEngine/NoteFonts管权重抽样与字形路径；NoteEditGeometry/NoteTextEditor管输入命中；NoteRecovery管独立恢复稿与关闭策略。

`connection/ConnectionService.java`管理串口发现、固件确认、取消、断线抑制；DevicePort按身份筛选USB设备。`src/com/kenjoy/uitrial/MachinePanelWorkflow.java`管理书写来源、任务冻结、中断清除与等待说明；NativeDpi/ResponsiveWorkspace分离界面与加工比例。`UpdatePatcher.java`和FontPatcher只做目标本地补丁事务、备份与回滚；不执行设备动作。

原软件通过EXE/加密加载器启动，补丁采用覆盖类及少量字节码改写，保留ABI和无关方法。公开源码用于检查/重建安装器，不声称能从这些切片重建完整原应用。目标运行使用附带Java8；开发回归另测JDK21。不要把开发覆盖JAR加入正式classpath以掩盖安装漏类。

## 产品约定

- 首轮直接编辑仅“笔记”。中文IME提交/取消、删改换行、跨页选区、连续操作撤销重做要可靠。未改字形稳定；新字按当前所选字体权重抽样，短段落不保证精确比例。改默认设置用于后续输入，“更新”才整篇重随机自动字，保留手动字体。
- 复制粘贴新抽样；同一文章剪切移动保留字体、字形和身份。撤销重做不重新抽样。输入法预编辑和临时系统字体只显示，不进入正文历史/机器路径。
- 缺字保留正文且红框；仍缺字、布局未完成、页面设置未应用时，禁止新导出/新书写，不能输出上次旧布局。这改变了旧0.024“缺字留空输出”的行为。
- 英文点`.`、全角点`．`与中文句号`。`不同。全角点缺字时借同字体英文点，自动候选都缺时内置矢量点；手动字体两种点都缺仍报缺字，原文码点不变。
- 一字符批量替换整篇红框，空格允许、不支持字符拒绝且无副作用。改处蓝框，保存重开、恢复稿及撤销重做保持；红蓝框、光标不进入输出。
- 黑底浅笔迹只用于预览/编辑；图片/PDF白底黑笔迹，机器路径不因颜色改变。旋转加工时编辑临时转正，不能改任务共享方向。
- 默认独立恢复稿不覆盖主动保存原文；可设置关闭前询问。恢复验证要比较内容、已确定字形与蓝框，不只是恢复文件存在。
- 从当前笔记页启动时冻结A稿，运行中编辑B稿只用于下一任务；翻页、更新、改字体不得改变当前路径/方向。多页连续编辑不是自动换纸/自动书写所有页。
- 格式2能读旧1；直接编辑前旧程序不能读2，旧格式2读写可能丢蓝框。程序回滚不转换文章，兼容测试用副本，保留新稿原件。

## 你负责观察什么

先启动本目录采集器，监视心跳是否更新、有无collector-error。它记录的是进程统计和人工事件时间线，CPU为累计秒；端口只是Windows显示名，没有固件ACK/串口原始包，不会证明物理停机、队列执行或任务冻结。

你观察界面焦点/IME、光标、正文、字形、红蓝框、页面/方向、输出就绪、连接与任务来源提示、按钮状态、报错和操作延迟。操作者与实际纸面/录像共同确认机器运动、停机、笔离纸、起点/尺寸/方向和A/B稿。每个Bug记本地及UTC时间、用例ID、准确步骤、预期/实际、机器状态、复现次数，并用事件ID关联文章副本、导出路径及截图/录像。事实与根因假设分开。

0.026修复了PowerShell进度CLIXML和JSON混流：stdout/stderr并行读取，仅stdout解析，不用setLenient掩盖。发现端口后仍必须匹配固件身份；COM打开不算连接完成。读取现有界面/合法已有日志即可，不开第二个串口终端抢占端口。

缺字书写门槛需要已验证连接、机器静止且来源为当前笔记页时测试；断开状态点击只会命中连接检查，不能算缺字门槛通过。A/B冻结测试需取消外部G-code来源且不是K_AT队列；直接发送导出的A.gcode不能证明笔记冻结逻辑。

## 动作与故障边界

你可独立做离线测试、只读采集和证据分析；机器回零、点动、抬落笔、空跑、落笔与故障注入分别由操作者明确确认。用户负责现场急停方式、有效范围、限位、速度、笔高、坐标及纸张。串口打开可能让硬件复位，现场记录，不推定软件没发动作就一定没复位。

异常运动先现场处置，不用杀程序模拟急停。控制板可能继续执行缓存，所以软件停止/断开不证明物理停机。确认停机后才能清除中断任务、重启/重连或开始新任务。生成器未退出时清除入口应禁用；迟到回调不能复活任务；超过30秒只说明等待，不重发、不自动丢弃长命令。首轮只测静止断线，运动中拔线需另定受控方案与明确授权。

故障先标记、保留现场，不反复点书写试探，不覆盖唯一原稿；安全停止后保存副本、对应路径和错误片段。日志/恢复稿/转储可能含正文和路径，回传前审查；不要上传许可、全量用户目录、连接记忆或完整配置。没有必要不取内存转储、不写固件参数。
